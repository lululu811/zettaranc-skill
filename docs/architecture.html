01项目总览

双轨定位

本项目是两条互不干扰、同时并行的轨道，刻意做了分层，这是理解全局的第一把钥匙：

轨道 A · 思维框架（核心交付物）

SKILL.md 是一份 Skill-Schema-V2 合规的角色扮演协议，被 Claude Code / Cursor 等宿主加载后，让 LLM 用「Z 哥」的角色口吻生成点评、话术、复盘。

语料基础：467 篇直播/付费课（~200 万字）、13 篇 ztalk transcript（12.7 万字）、9 篇交易心理系列、雪球专栏及网络预研。

交付物：SKILL.md + knowledge/（32 篇）+ rules/ + references/

轨道 B · 量化数据工具

Python 包 modules/ 只负责数据准备：指标计算、战法信号、选股评分、回测、验收。

刻意不做投资话术——把「算数」和「说话」分开，避免 LLM 生成的数据带有「AI 味」或幻觉价格。

交付物：modules/（135 py）+ api/ + frontend/ + rust/

分层原则：modules/ 输出的是结构化事实（J 值、量比、信号、评分、绩效指标）， SKILL.md 负责把事实翻译成人话。数据层缺 key 时绝不编造价格/信号，只明确报告当前数据状态。

两种运行模式

模式环境变量外部依赖能力适用场景

components：_rust_compat.py 三态切换

# 环境变量 ZETTARANC_BACKTEST_IMPL = rust（默认）| python | auto
rust   → 强制使用 Rust；import 失败抛 RuntimeError（不静默）
python → 永远返回 None，走 Python 实现
auto   → 优先 Rust；import 失败静默降级 Python

# 业务层标准写法（注意：用 is not None，不能用 or —— Rust 成功返回 falsy 值会被误判）
fn = compute_func("run_single_strategy_backtest_py")
if fn is not None:
    result = fn(config, klines)
else:
    result = python_fallback(config, klines)
陷阱：auto 模式降级是静默的，容易掩盖 Rust 回归。CI 用 tests/test_rust_compat.py + tests/test_cli_uses_rust.py 覆盖接线。缓存是 env 感知的，monkeypatch 后自动失效。

12关键约定（改动前必读）

单一事实来源

概念唯一定义位置禁止行为

编码约定

  • 语言：中文文档字符串/注释；脚本文件头 #!/usr/bin/env python3
  • DB 访问：统一 modules/database.py::get_connection() 上下文管理器（WAL + 自动 commit/rollback）
  • 环境变量：仅 modules/__init__.py 首次 import 时 load_dotenv(override=False)；子模块禁止重复加载
  • 限流：所有 Tushare API 调用必须带 _rate_limit()
  • 错误处理：API 调用 try/except 包裹，记录 error log，返回空 DataFrame/None 而非抛异常中断
  • DB-first 读：K 线/指标先查 daily_kline/indicator_cache，未命中才调 API 并写回
  • Rust 桥判断：if result is not None，不要用 or（Rust 成功返回 falsy 值会被误判）
  • Ruff：line-length 120，target py312，select F/E/W/UP，ignore E501/F401/F403；format 双引号 + 空格
  • Mypy：py3.12，ignore_missing_imports，仅关键路径类型检查（screener/cli/data_sync/indicators/core/strategies），非严格渐进
  • 安全：敏感 key（TUSHARE/INDEVS/HITHINK/LLM/webhook）绝不硬编码，全部走 .env（gitignored）
